## 📌 Descripción del proyecto
Este repositorio contiene el código fuente utilizado para crear y gestionar una base de datos NoSQL en MongoDB, correspondiente al caso de uso **"Dueños y Mascotas"**.

La base de datos incluye:
- 1 colección de dueños (owners)
- 1 colección de mascotas (pets)
- Inserción de **100 mascotas**
- Consultas básicas, avanzadas y agregación
